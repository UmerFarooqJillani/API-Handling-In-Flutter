# <p align="center"> Why Models </p>

A model (often called a Data Model or DTO) serves as a structured blueprint that defines how data is exchanged between a client and a server. Using models is essential for ensuring that both the sender and receiver understand exactly what data to expect and in what format.
1. **Data Validation and Consistency**
    - Type Checking
    - Mandatory Fields
    - Error Prevention (validating data against a model before processing)
2. **Standardization and Documentation**
    - Blueprint for Developers
    - Predictability
